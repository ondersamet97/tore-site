# töre — website

Source of the töre website: <https://ondersamet97.github.io/tore-site/>

töre is a personal knowledge tool in development. This repository contains only the static website (English and Turkish), not the application.

- `index.html` — English
- `tr/index.html` — Turkish
- `styles.css` — styles
- `brand/` — logo and icons
- `tools/make_icons.py` — regenerates the PNG icons (Python standard library only)

The site makes no external requests and has no tracking.
